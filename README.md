# La Rioja en 5 Pistas

Juego web estático para GitHub Pages.

## Archivos
- `index.html`: página principal.
- `style.css`: diseño.
- `script.js`: funcionamiento.
- `enigmas.js`: los 50 enigmas exportados del Excel.
- `logo.png`: cabecera/logo.
- `La_Rioja_en_5_pistas_50_enigmas.xlsx`: base de referencia.

## Publicación
Sube todos los archivos al repositorio y activa GitHub Pages desde `Settings → Pages`, seleccionando la rama `main` y la carpeta `/ (root)`.
